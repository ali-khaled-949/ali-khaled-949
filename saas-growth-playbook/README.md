# SaaS Growth Playbook — ScopeGuard

The five "Act as an expert" prompts (AI Tool Builder, SaaS Revenue Builder, Viral Product Designer, Launch Expert, Churn Reducer), answered as one plan for one product, so each section builds on the one before it.

**Niche assumed:** freelance developers and small dev agencies (1–10 people).
**Product:** **ScopeGuard** is an AI tool that turns client call notes and emails into a scoped proposal. It then watches incoming client requests and flags scope creep, with a ready-to-send change order.

To use a different niche, change `docs/01` and the numbers in `docs/02`. The rest of the plan still applies.
